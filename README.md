# 累積標高を計算するAndroidアプリ

移動ルートの標高データから、累積上昇標高と累積下降標高を計算するAndroidアプリです。

## 開発状況

企画・要件整理の段階です。アプリの実装はまだありません。リポジトリ名は `electron` ですが、対象プラットフォームはAndroidです。

## 最初のバージョンで目指すこと

- 標高データを取り込む。
- 累積上昇標高と累積下降標高をそれぞれメートル単位で表示する。
- データ不足や標高欠損を明示する。
- 標高データの細かな揺れによる過大計算を抑える方法を検討し、採用した処理を明記する。

## 計算の基本

連続する有効な標高点の差について、正の差を上昇量として合計し、負の差の絶対値を下降量として合計します。例えば `100 → 120 → 110 → 140 m` では、補正なしの場合、累積上昇は `50 m`、累積下降は `10 m` です。開始点と終了点の標高差とは異なります。

区間の切れ目や欠損をまたぐ差分の扱い、ノイズ補正の方式とパラメータは実装前に決定します。

## 未決定の事項

- 入力方法：GPXファイル、端末GPSによる記録、地図上のルート指定から選定する。
- Androidの対応バージョンと開発技術。
- データ保存、地図表示、バックグラウンド記録の必要性。

## 開発の進め方

GitHub Issuesで要件と開発タスクを管理します。入力方法の決定後、Androidの基盤、データ取得、計算処理、結果画面の順に具体化します。初期README以降のコード変更はブランチとPull Requestで確認します。
